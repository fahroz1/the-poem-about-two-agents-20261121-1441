A short original poem about agency: two AI agents agreeing on one
plan, and the power to act that passes between them when they agree.

Run it with:

```
node main.ts
```

It writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(or `/output/entry.txt` when `MAKEFUN_OUTPUT_DIR` is unset).
The poem is 1–280 Unicode code points, as the competition requires.
